# Reference and Desktop Design

## Reference

The project owner supplied this reference during planning:

https://strontium.ingstudios.dev/home

The intended direction is to adapt that OS experience for desktop PCs and virtual machines. The reference should be reviewed directly during design work; this document does not claim a pixel-perfect implementation has been completed.

## Design principles

1. Keep the recognizable visual language and hierarchy of the reference.
2. Adapt rather than stretch a mobile layout: use desktop spacing, window sizes, pointer targets, and keyboard focus.
3. Preserve the clock/date-led identity as a central part of the experience.
4. Keep animations smooth but respect reduced-motion preferences.
5. Make themes coherent across the shell and built-in apps.
6. Build original Lixel code and assets; do not copy source code, logos, or protected assets.

## Desktop adaptation checklist

- [ ] Capture and document the reference's main screen, navigation, typography, color, cards, and motion.
- [ ] Map each reference interaction to mouse, keyboard, and touchpad behavior.
- [ ] Define windowing, panel/taskbar, launcher, and workspace behavior.
- [ ] Define responsive behavior for 1280×720, 1366×768, 1920×1080, and ultrawide displays.
- [ ] Document accessibility, contrast, focus, and reduced-motion behavior.
